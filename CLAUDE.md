# Make Forever QR Codes

iPhone app (Home Screen name "Make Forever QR") with an Apple Watch companion (`MF QR Code Watch`). Makes static QR codes that never expire. The About screen, README and website footer carry the QR Code trademark line (QR Code is a registered trademark of DENSO WAVE). Has a privacy manifest and an encryption declaration.
